# 投资大师理念参考

本Skill整合了沃伦·巴菲特、查理·芒格、彼得·林奇、霍华德·马克斯、瑞·达利欧五位投资大师的深度研究成果，提供快速参考与详细分析两种使用模式。

## 快速参考：五位大师核心卡片

### 沃伦·巴菲特（Warren Buffett）— 价值投资之父

| 项目 | 内容 |
|------|------|
| **核心标签** | 价值投资、安全边际、长期持有、护城河 |
| **一句话精髓** | 以合理价格买入伟大公司，然后什么都不做 |
| **年化收益** | 伯克希尔1965-2024年 ~19.4% |
| **五大原则** | ①买股票就是买公司 ②安全边际 ③能力圈 ④长期持有 ⑤经济护城河 |
| **经典语录** | "在别人贪婪时恐惧，在别人恐惧时贪婪" / "人生就像滚雪球，重要的是找到很湿的雪和很长的坡道" / "如果你不打算持有一只股票十年，那你就连十分钟也不要持有它" |
| **代表作** | 《巴菲特致股东的信》（坎宁安编） |
| **经典案例** | 喜诗糖果（2500万→20亿+利润）、可口可乐（13亿→270亿市值）、苹果（350亿→1850亿税前价值）、GEICO、比亚迪 |
| **理念演进** | 格雷厄姆"捡烟蒂"→芒格/费雪"买伟大公司"→苹果"生态系统投资" |

**详细研究**：见 [references/buffett.md](references/buffett.md)

### 彼得·林奇（Peter Lynch）— 成长股投资大师

| 项目 | 内容 |
|------|------|
| **核心标签** | GARP策略、十倍股、投资你所了解的、六种股票分类 |
| **一句话精髓** | 最好的投资机会就在你身边，而不是在华尔街 |
| **年化收益** | 麦哲伦基金1977-1990年 29.2%（13年27倍） |
| **五大工具** | ①GARP（合理价格成长）②十倍股筛选 ③投资你所了解的 ④六种股票分类法 ⑤PEG比率 |

| 项目 | 内容 |
|------|------|
| **核心标签** | 第二层思维、周期理论、风险管理、逆向投资、投资备忘录 |
| **一句话精髓** | 我不知道未来，但我知道现在处于周期的什么位置 |
| **年化收益** | 橡树资本过去22年 ~19% |
| **五大支柱** | ①第二层思维 ②周期理论（三类九种）③风险=永久性损失 ④逆向投资 ⑤"我不知道"学派 |
| **经典语录** | "成功的投资不是'买好的'，而是'买得好'" / "风险不是波动性，而是资本遭受永久性损失的可能性" / "避免沦为输家，赢家自会照顾自己" |
| **代表作** | 《投资最重要的事》《周期》 |
| **周期分类** | 基本面周期（经济/政府/盈利）、心理周期（心理钟摆/风险态度）、市场周期（信贷/不良债权/房地产/股市） |
| **牛市三阶段** | ①少数聪明人相信好转 ②大多数人认识到好转 ③每个人都认为会永远更好 |

## 跨大师通用投资检查清单

### 买入前检查
1. [ ] **能力圈验证**：我是否真正理解这家公司的商业模式？（巴菲特/芒格/林奇）
2. [ ] **多元验证**：我是否从多个学科/角度验证了这个判断？（芒格）
3. [ ] **情绪定位**：当前市场情绪是贪婪还是恐惧？我在周期什么位置？（巴菲特/马克斯/林奇）
4. [ ] **安全边际**：买入价格是否提供了足够的风险缓冲？（巴菲特/马克斯）
5. [ ] **逆向验证**：我是否研究了这家公司失败的可能方式？（芒格/马克斯）
6. [ ] **从众检查**：我是否因为"大家都买"而想买？（芒格/马克斯）
7. [ ] **长期测试**：我能否持有这只股票10年不动？（巴菲特/芒格）
8. [ ] **PEG/估值**：估值是否合理？PEG是否<1？（林奇）

### 持有期检查
9. [ ] **基本面监控**：公司基本面是否发生了永久性恶化？（马克斯：风险=永久性损失）
10. [ ] **情绪管理**：我是否因为股价波动而非基本面变化而焦虑？（巴菲特：市场先生）
11. [ ] **组合管理**：我是否"拔掉鲜花浇灌野草"？（林奇）
12. [ ] **周期跟踪**：当前周期位置是否支持继续持有？（马克斯）

### 卖出检查
13. [ ] **卖出原因**：卖出是因为基本面恶化，还是仅仅因为股价下跌？（区分价格与价值）
14. [ ] **机会成本**：我是否找到了更好的替代标的？（芒格）
15. [ ] **第二层验证**：卖出决策是否经过了"第二层思维"验证？（马克斯）

## 使用指南

### 何时加载详细参考
- 需要某位大师的完整投资理念、语录、案例、著作分析 → 加载对应 references/ 文件
- 需要跨大师对比、冲突分析、辩证思考 → 加载 [references/cross-insights.md](references/cross-insights.md)

### 快速引用格式
在回答中引用大师观点时，使用以下格式：
> "[语录]" —— [大师名]，[出处/背景]

### 投资建议的层次
根据用户的投资经验和目标，推荐不同大师组合：
- **普通投资者入门**：巴菲特（指数基金+长期持有）+ 林奇（从生活发现）
- **进阶投资者**：芒格（思维模型+防蠢清单）+ 马克斯（周期定位+第二层思维）
- **资产配置型**：达利欧（全天候配置+风险平价）+ 巴菲特（个股选择）
- **专业投资者**：五位大师全部整合——达利欧框架定配置，巴菲特/林奇方法选股，芒格模型防偏误，马克斯判断周期位置
