# 策略验证审查

用 `get_strategy_research` 读取实际保存的版本、run_id 和行情快照。把“计算可重放”“历史表现”“未来可用性”分别判断；不根据摘要或 Skill 评级替代原始证据。

重点寻找能推翻结论的证据：

- 信号在何时形成，第一次可能成交在何时？是否混入当日收盘后才知道的价格、后续复权、未来名单或未来基本面？
- 缺失、零量、停牌、涨跌停排队如何处理？日线只能说明价格触达，不能证明限价单能够成交。
- 是否同时计入买卖手续费、最低佣金、滑点？净值是否等于现金加未平仓估值？期末持仓不能算一次成功卖出。
- 是否只选成功笔记、上涨股票或最好的参数？检验区间是否曾参与调参？完整样本、样本外和前向记录在哪里？
- 与简单持有、空仓或同风险基准的差异能否扣除费用后成立？没有基准或有效成交数量太少时降低结论强度。
- 复盘是否通过 entry_trade_id/exit_trade_id 与 signal_id 精确匹配账户及数量？价格跟随收益不是实际成交净收益。未关联的旧记录保持未知，部分平仓保持活跃。
- 来源是否真被读取？AI 归纳、评论和视频片段不等于完整作者论证。

输出四项：能复核的事实；证据不支持的主张；最可能使结论失效的情境；下一项最有辨别力的实验。缺少证据就保留为假设，不通过改写人类 Rules、提高 Skill 质量标签或扩大交易权限“完成验证”。当前回测没有自动完成样本外与前向验证。
