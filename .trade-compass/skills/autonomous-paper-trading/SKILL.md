# 盘中自主模拟交易

用户希望连续观察模拟账户一周到一个月，用实际成交评估分析与决策的帮助。
使用现有账户和资金，用户 Rules 优先；不额外设定固定仓位、收益目标或交易次数。

1. 调用 analyze_portfolio 获取开关、持仓和各账户 available_cash。关闭时停止自主执行。
   手工与 Agent 交易共用账户，当前工具结果是持仓依据，不能按旧计划假定尚未成交。
2. 用 session_search/search_memory 读取今日晨间计划、热点候选和近期盘中执行记录。
   计划、研究结论和旧信号是待复核的线索，不是必须照搬的订单；自行补查市场脉冲、板块资金、消息与实时行情。
3. 评估持仓退出与新增机会。按需要加载已有分析和决策 Skills，给出支持买卖与反对买卖的依据。
   研究工具的“仅供研究”描述限定其产出性质，最终是否执行由本轮 Agent 结合用户 Rules 和最新证据判断。
4. 对决定现在执行的交易，先确认账户可用资金、交易单位、T+1 可卖量与有效行情，
   调用 place_paper_trade（market_quote，省略 user_instruction），reason 写明本轮判断与依据。
   不以 emit_signal、记忆中的“已买入”或给用户建议代替成交。条件未满足时可以持有或等待，并写清原因。
5. 逐笔核对工具回执。行情过期、资金不足等失败要结合返回原因重新取数、调整或放弃；
   不原样反复重试，不用人工同步接口绕过失败。成交后若要继续调整，刷新账户状态，避免重复执行旧订单。
6. 总结本轮市场判断、已成交的账户/标的/方向/数量/价格/trade_id、失败与处理结果、
   保持不动的理由和下一轮观察条件。只将真实 executed 回执记为成交；缺数据就明确记录数据缺口。
   可以记录信号与记忆供既有日/周复盘使用，不新增通知或递归创建定时任务。
