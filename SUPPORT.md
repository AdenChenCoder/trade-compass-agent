# Support

Use the channel that matches the request:

- **Installation, configuration, or usage problem:** search existing issues,
  run `trade-compass doctor`, then open a bug report with redacted output.
- **Feature or product proposal:** open a feature request and describe the
  observable user outcome before proposing implementation.
- **Contribution question:** read [CONTRIBUTING.md](CONTRIBUTING.md) and comment
  on the relevant issue or pull request.
- **Security vulnerability or leaked credential:** follow
  [SECURITY.md](SECURITY.md). Do not open a public issue.

Before sharing logs or examples, remove API keys, webhook secrets, local paths,
portfolio exports, account details, and private research content.

This is a community-maintained open-source project; response times are
best-effort. A reproducible example and `trade-compass --version` output make
support substantially faster.
