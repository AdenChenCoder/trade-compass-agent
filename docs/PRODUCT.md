# Product

## Register

product

## Users

Chinese-speaking A-share researchers and investors using a local workbench on a
computer and continuing conversations or reading task results on a phone.
The interface supports sustained reading of research, financial tables and history.

## Product Purpose

Trade Compass Agent joins Agent conversations, simulated portfolios, strategy
research, memory, user rules, skills, scheduled jobs and audit records in a local-first
Python package. UI changes preserve their shared API and authoritative records.

## Brand Personality

Clear, confident, modern. The requested redesign uses bolder color and more visible
motion while keeping data and operation consequences readable.

## Anti-references

Do not turn the workbench into a marketing landing page, invent financial statistics,
add developer status copy, or obscure operational errors with decorative effects.

## Design Principles

- Preserve access to existing history, rules and controls.
- Distinguish research context, incomplete results and executable actions.
- Make frequent operations easy to find across screen sizes.
- Use one shared component vocabulary and retain the existing coin identity.

## Accessibility & Inclusion

Support keyboard navigation, visible focus and reduced motion. Keep semantic
status labels alongside colors. Respect Chinese text readability and mobile safe areas.
